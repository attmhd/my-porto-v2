# My Porto v2

Portfolio website built with React, Vite, and TypeScript.

## Quick start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy env template:
   ```bash
   cp .env.example .env
   ```
3. Run locally:
   ```bash
   npm run dev
   ```

## Environment Configuration

Create a `.env` file in the root directory and configure the following variables:

```env
# Supabase Configuration
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_SUPABASE_PORTFOLIO_TABLE=portfolio_state
VITE_SUPABASE_PORTFOLIO_ROW_ID=current

# Gemini AI Configuration
GEMINI_API_KEY=your_gemini_api_key
```

The app will use Supabase when credentials are present, and fall back to localStorage otherwise.

## AI Features & Mechanics

This portfolio features powerful client-side AI integration powered by **Google Gemini**:

### 1. ✨ AI Chatbot Assistant (`AIChat.tsx`)
A conversational assistant running directly in the browser that answers visitors' questions based on your custom portfolio structure and details.
* **Rate Limiting Protection:** To prevent spam, brute force, and api exhaustion, a sliding-window rate limiter restricts users to a maximum of **9 requests per minute**.
* **Smart Persistency:** The request window history is stored in browser `localStorage` to persist across page reloads, falling back gracefully to an *in-memory* tracker if storage permissions are restricted (such as in Incognito/private mode).
* **Interactive UI Warnings:** Displays a friendly warning indicating exactly how many seconds remains before they can chat again (e.g. `⚠️ Rate Limit: Rate limit exceeded. Please wait 45 seconds before trying again.`).

### 2. 📝 AI Blog Writer Assistant (`BlogSection.tsx`)
An interactive, automated copywriting assistant integrated directly into the blog administration panel to draft or refine articles.
* **Streaming Outputs:** Content generated by Gemini streams live *chunk by chunk* into your editor so you can see it writing in real-time.
* **Metadata Contextualization:** Synthesizes the Title, Description, and Tags of your blog draft to create highly relevant, SEO-optimized, and personalized Markdown articles.
* **Smart Insertion Modes:** Offers an automatic check to either **Append** the generated content to the end of your current draft or **Overwrite** the editor entirely.
* **Custom Instructions:** Allows specifying detailed instructions (e.g., *"Focus on React 19 server actions, include code examples, use a friendly tone"*).

## Supabase setup

1. Create a Supabase project.
2. Run the SQL in `supabase/migrations/0001_portfolio_state.sql`.

## Structure

- `src/components` - reusable UI components
- `src/pages` - route-level pages
- `src/data` - shared content and portfolio models
- `src/services` - API and persistence layers
- `src/contexts` - React providers
- `src/hooks` - custom hooks
